# Звіти лабораторних

Звіт з кожної лабораторної — **PDF за кафедральним шаблоном** (рамки зі
штампом, Times New Roman 14, інтервал 1,5) — здається **в Moodle**
(Assignment «Лабораторна N»). Шаблон і вимоги до оформлення — у Moodle,
секція «Загальне».

Копію звіту можна (не обов'язково) покласти сюди як `labN.pdf` — тоді
версія звіту буде зафіксована тегом разом із кодом. Зображення для
README/записки — у `assets/`.

Структура звіту повторює чекліст лабораторної: умова кожного завдання →
результат (скріншоти, лістинги, посилання на файли репозиторію) → висновки.
